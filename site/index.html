Remote control for your own Macs and PCs

Every computer in the house, from the one you're sitting at. Nothing leaves your network.

Raven shows another computer's screen and lets you use its mouse and keyboard. It also moves files, shares the clipboard, and puts the computer to sleep, shuts it down or wakes it up. It works between Windows and macOS, with no accounts and no cloud.

What it does

Everything you'd walk to the other room for

See the screen, use the mouse and keyboard

Pick a display, choose between smooth and sharp, or switch to view only. ⌘ and Ctrl swap automatically between a Mac and a PC, so shortcuts do what you expect.

JPEG frames, sent only when the screen changes · up to 20 fps

Sleep, lock, restart, shut down

One click on a device card, without opening its screen. Restart and Shut Down ask before they act.

pmset on macOS · SetSuspendState and shutdown on Windows

Wake it back up

After the first connection Raven remembers the computer's network card, and the Wake button turns it on again from sleep, or from a full shutdown on many PCs.

Wake-on-LAN magic packet · UDP ports 9 and 7

Move files both ways

Browse the other computer's folders, download whole folders, upload into any of them, or drop files onto the remote screen to send them to its Downloads folder.

SHA-256 checked on arrival · never overwrites a file

One clipboard for both

Copy text or a screenshot on one computer and paste it on the other, in either direction, while the remote screen is open.

text up to 4 M characters · images up to 16 MB

Finds your computers for you

Computers running Raven appear on their own, with a live online or offline status. You can still add one by its address.

Bonjour / mDNS · service _raven._tcp

The app

One app on every computer

Each computer can control the others, be controlled, or both. The app follows your system's light or dark mode.

Devices

Every computer you can reach, as a card.

  • Connect opens its screen in a new window.
  • The moon puts it to sleep; the power menu locks, restarts or shuts it down.
  • Offline computers get a Wake button.

This computer

One switch lets your other computers in, protected by a password you choose.

  • Separate switches for mouse and keyboard, power, files and clipboard.
  • Your address and fingerprint, ready to copy.
  • An activity feed of every connection and every file received.

Files

The other computer's folders, as if they were yours.

  • Home, Desktop, Documents, Downloads and drives in the sidebar.
  • Download, upload, new folder, or drag files in from your desktop.
  • Progress, speed and cancel for every transfer.

How it works

One encrypted connection, inside your network

Everything travels over a single TLS connection between the two computers. Only discovery and wake-up packets travel outside it, and they never leave the local network.

Found

The host announces itself on the network, so its card appears on your other computers with an online dot.

Verified

The first time you connect, you compare the host's fingerprint with the one shown on its screen. After that, a changed identity triggers a warning.

Connected

Your password proves itself without crossing the wire. Screen, input, files and clipboard then share the one connection.

Security

Built for a network you don't fully trust

Café Wi-Fi, a shared flat, a busy office: Raven assumes someone else on the network might be hostile.

Local network only

A host refuses any connection from outside private address ranges, before the first message, even if a router port is forwarded by mistake.

Encrypted and pinned

Every connection uses TLS with the computer's own certificate. Raven remembers each certificate and warns you if one ever changes.

Your password never travels

Login is a challenge and response built on PBKDF2 with 200,000 rounds, tied to the certificate. A computer pretending to be yours can't collect anything cheap to crack.

Guessing is slow

Five password attempts per address per minute, and 30 for the whole computer. Attempts sent at the same time all count.

The host stays in charge

Turn off mouse and keyboard, power, files or clipboard separately, mid-session if you like. Every connection and received file is logged, and one button disconnects everyone.

No tricks in names

Names and messages from other computers are shown as plain text, with hidden characters removed. File names can't escape the folder you chose or disguise an .exe as an image.

Get started

Set up in three steps

You need Python 3.10 or newer on each computer. Prebuilt Windows and macOS apps are also produced by the project's build on every change.

Install Raven on each computer

Clone the repository, then install it into a virtual environment.

git clone https://github.com/ShehanEk/project-raven.git raven
cd raven
python -m venv .venv
# Windows: .venv\Scripts\activate   macOS: source .venv/bin/activate
pip install -e .
raven

Turn on Remote access on the computer you want to control

Open This computer, switch on Remote access and choose a password. Turn on Start at login to keep it reachable after a restart.

Connect from your other computer

Open Devices and press Connect on its card. The first time, check that the fingerprint matches the one on the other screen, then enter the password.

On a Mac

Allow Raven under Screen Recording and Accessibility in System Settings → Privacy & Security, then restart Raven. The app has buttons that open both pages.

On Windows

Allow Raven through Windows Defender Firewall on Private networks when asked. For Wake-on-LAN, enable it in the network adapter's power settings.
